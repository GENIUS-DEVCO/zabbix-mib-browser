# MIB fournies avec le module

Ces fichiers sont chargés automatiquement (source « Standard ») et ne peuvent pas être supprimés depuis l'interface. Pour ajouter des MIB constructeurs, utilisez l'onglet **MIB chargées** du module : elles sont enregistrées dans `data/mibs/`.
